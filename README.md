# Dotfiles

```bash
git clone git@github.com:PedrFelip/dotfiles.git ~/Projects/dotfiles
cd ~/Projects/dotfiles
./scripts/install
```

Inclui configurações do Bash, Starship, Ghostty, Tmux, Hyprland, Neovim,
Omarchy e Zed.

O instalador usa o `yay` para instalar a fonte `otf-departure-mono` e o
`pacman` para instalar o GNU Stow, caso necessário.

Os plugins do Omarchy são baixados diretamente do GitHub durante o setup.
